Basicamente algo que eu fiz para me auxiliar em um jogo que eu jogo!
Teclas principais:
Numpad 5| Aumenta prestigios
Numpad 0| Diminui prestigios
Del| Liga o modo digitação de numeros (e menos na frente para diminuir)
Enter| Confirma os numeros e aplica ao contador
+| Liga e desliga o Spinbreak tracker
-| Pausar o timer
*| Estatisticas

Uhh if anyone is wondering how it works:
Numpad| 5 and Numpar 0 to increase/decrease Prestiges 
Del| Turns on the typing mode to increase spins, press del and a number ex: 300 and them enter (u can subtract putting - at front)
Enter| Just confirm the spins input
+| Disable the spinbreak counter
-| Pause the session timer/total timer
*| Open up the statistics
